## 1. ماذا يفعل هذا البوت

البوت يشتغل بالكامل على سيرفرات GitHub — **مش محتاجة تفتحي أي كمبيوتر عندك**. كل يوم بشكل تلقائي:

1. يجيب منتجات جديدة من **amazon.com** (مرة واحدة يومياً الساعة 5 صباحاً بتوقيت الرياض).
2. في كل واحد من الـ 10 أوقات المجدولة، يختار المنتج التالي من القائمة.
3. يحمّل سكرين شوت من صفحة المنتج على أمازون (أو صورة المنتج بجودة عالية كنسخة احتياطية).
4. يبني فيديو قصير 15 ثانية مناسب لـ TikTok.
5. يكتب كابشن تسويقي بالعربية مع أكواد العروض بتاعتك ورابط الأفلييت.
6. ينشر:
   - **تيليجرام** ← صورة + فيديو + كابشن في قناتك
   - **X (تويتر)** ← صورة + كابشن
   - **Pinterest** ← بن مع صورة + كابشن + رابط أفلييت
7. كل روابط الأفلييت بتستخدم التاج الأمريكي بتاعك (`electron039ae-20`) وبتوجّه لصفحات المنتجات الحقيقية على amazon.com — العمولات هتتحسب صح.

## 2. جدول النشر اليومي

المنشورات تنزل في هذه الأوقات (**بتوقيت الرياض** UTC+3):

```
09:00 · 10:00 · 12:00 · 14:00 · 16:00 · 17:00 · 18:00 · 20:00 · 21:00 · 22:00
```

مرة يومياً الساعة **05:00 بتوقيت الرياض**، مهمة منفصلة تجيب 10 منتجات جديدة وتحطهم في القائمة.

## 3. كيفية الوصول للبوت

البوت موجود على GitHub في العنوان التالي:
```
https://github.com/YOUR_USERNAME/Affilate_bot
```

- سجّلي دخول بحساب GitHub اللي تم تحويل الملكية له.
- كل شيء تحتاجينه في مكان واحد — الكود، والجدولة، والمراقبة، والأسرار.

## 4. كيفية التأكد أن البوت يعمل

1. افتحي المشروع على GitHub → اضغطي على تاب **"Actions"** (أعلى الصفحة).
2. هتلاقي في القائمة على اليسار مهمتين:
   - **"Post — publish next product to all 3 platforms"**
   - **"Scrape — refill product queue"**
3. اضغطي على أي واحدة عشان تشوفي التشغيلات الأخيرة — علامة الصح الخضراء = نجاح، علامة X الحمراء = فشل.
4. اضغطي على أي تشغيل عشان تشوفي التفاصيل.

**GitHub هيبعتلك إيميل تلقائي لو أي تشغيل فشل**، فمش محتاجة تراقبي بشكل مستمر.

## 5. ما يمكنك تخصيصه

تقدري تعدّلي أي ملف مباشرة من GitHub — **مش محتاجة تنصّبي أي شيء على الكمبيوتر**.

**كيف تعدّلي أي ملف على GitHub:**
1. افتحي الملف من داخل المشروع (اضغطي عليه).
2. اضغطي على أيقونة القلم ✏️ فوق على اليمين.
3. عدّلي النص.
4. انزلي تحت → اضغطي زر **"Commit changes"** الأخضر.
5. أكّدي — التشغيل المجدول التالي هيستخدم القيم الجديدة.

### 5.1 تغيير أسطر العروض (كود البنك + كود القناة)

**الملف:** `config.example.json`

البوت بيحط سطرين قابلين للتخصيص في كل كابشن. القيم الافتراضية:
```
فعّل خصم بنك الراجحي 25% ⬅️
فعّل كود القناة 15% ⬅️
```

عشان تغيّريهم، عدّلي هذين السطرين في `config.example.json`:
```json
"captions": {
  "language": "ar",
  "bank_discount_line": "فعّل خصم بنك الراجحي 25% ⬅️",
  "channel_code_line": "فعّل كود القناة 15% ⬅️"
}
```

- غيّري النص اللي بين علامتي التنصيص لأي شيء تحبيه.
- عشان **تخفي سطر بالكامل**، خلّي قيمته فاضية: `"channel_code_line": ""`
- تقدري تكتبي عربي، إنجليزي، أو خليط — أي شيء بين علامتي التنصيص هيظهر في الكابشن.

### 5.2 تغيير بورد Pinterest

**الملف:** `config.example.json`

دوّري على:
```json
"pinterest": {
  ...
  "default_board": "for amazon"
}
```

غيّري `"for amazon"` لأي اسم بورد موجود على حسابك في Pinterest. لو البورد مش موجود، البوت هيعمله في التشغيل التالي.

### 5.3 تغيير عدد المنتجات في اليوم

**الملف:** `config.example.json`

دوّري على:
```json
"products_per_day": 10,
```

غيّري `10` لأي رقم. مهمة السحب اليومية هتجيب العدد ده من المنتجات لنشر اليوم التالي.

⚠️ **ملاحظة:** جدول النشر فيه 10 أوقات ثابتة (شوفي القسم 5.5). لو حطّيتي رقم أقل (مثلاً 5)، البوت هينفد منه المنتجات قبل ما اليوم يخلّص.

### 5.4 تغيير أنواع المنتجات اللي البوت يسحبها

**الملف:** `scraper/categories.json`

هذا الملف فيه التصنيفات اللي البوت يدور بينها. الشكل العام:
```json
{
  "groups": [
    {
      "id": "group_1",
      "name": "اسم المجموعة",
      "categories": [
        { "name": "ملابس", "query": "clothing" },
        { "name": "أحذية",  "query": "shoes" }
      ]
    }
  ]
}
```

- **`query`** هو اللي بيتم البحث عنه فعلاً على amazon.com — **اكتبيه بالإنجليزي**.
- **`name`** مجرد تسمية لعرضك الشخصي.
- تقدري تضيفي، تحذفي، أو تعيدي الترتيب زي ما تحبي.

كبديل، عشان تتخطي التصنيفات وتستخدمي رابط بحث واحد، عدّلي `config.example.json`:
```json
"amazon": {
  "source_url": "https://www.amazon.com/s?k=home+improvement"
}
```

غيّري `home+improvement` لأي كلمات مفتاحية (استخدمي `+` بدل المسافات).

### 5.5 تغيير أوقات النشر

**الملف:** `.github/workflows/post.yml`

الملف ده تقني شوية، لكن تقدري تعدّلي جدول الـ cron. دوّري على قسم `schedule:`:

```yaml
schedule:
  # 09:00 Riyadh = 06:00 UTC
  - cron: "0 6 * * *"
  # 10:00 Riyadh = 07:00 UTC
  - cron: "0 7 * * *"
  # (إلخ)
```

- كل سطر `- cron:` هو موعد نشر واحد، **بتوقيت UTC**.
- عشان تحوّلي من توقيت الرياض لـ UTC، اطرحي 3 ساعات (الرياض 09:00 = UTC 06:00).
- الصيغة: `"MINUTE HOUR * * *"` — مثلاً `0 6 * * *` = الساعة 06:00 UTC يومياً.
- امسحي سطر عشان تحذفي موعد. أضيفي سطر `- cron:` جديد عشان تضيفي موعد.

## 6. الصيانة: تحديث كوكيز تسجيل الدخول

**المهمة الوحيدة المتكررة.** جلسات تسجيل الدخول لـ X و Pinterest بتنتهي كل **1-3 شهور**. لما ينتهون، النشر على X أو Pinterest يفشل (تيليجرام يفضل شغّال — بيستخدم نظام دخول مختلف).

لو GitHub بعتلك إيميل عن فشل، أو لاحظتي إن النشر على X أو Pinterest متوقّف، لازم يتم تحديث الكوكيز.

**الطريقة السهلة:** اطلبي من المطوّر مساعدتك — العملية تحتاج Python مثبّت على كمبيوتر.

**الطريقة الذاتية:** اتبعي الدليل التقني تحت.

<details>
<summary>اضغطي هنا للتوسيع: كيف تحدّثي الكوكيز بنفسك</summary>

1. **نصّبي Python** على أي كمبيوتر (ويندوز، ماك، لينكس): https://www.python.org/downloads/
2. **حمّلي المشروع** من GitHub → زر Code → Download ZIP → افتحي الملف المضغوط.
3. في terminal أو PowerShell، ادخلي داخل الفولدر ونصّبي المتطلبات:
   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   ```
4. **انسخي `config.example.json` لملف جديد اسمه `config.json`** واملي إيميل وباسورد Pinterest.

**لـ X:**
```
python -m posters.x_poster --login
```
هيفتح متصفح → سجّلي دخول في X → اضغطي Enter في الـ terminal → الكوكيز هتتحفظ في `x_cookies.json`.

**لـ Pinterest:**
```
python -m posters.pinterest_poster --headed
```
هيفتح متصفح → تسجيل دخول تلقائي → هينشر بن تجريبي صغير (تقدري تمسحيه) → الكوكيز هتتحفظ في `pinterest_cookies.json`.

**تحديث GitHub Secrets:**
1. على GitHub → مشروعك → Settings → Secrets and variables → Actions.
2. اضغطي ✏️ جنب `X_COOKIES_JSON` → الصقي محتوى ملف `x_cookies.json` كامل → Update.
3. اضغطي ✏️ جنب `PINTEREST_COOKIES_JSON` → الصقي محتوى ملف `pinterest_cookies.json` كامل → Update.

شغّلي Post يدوياً (Actions → Post → Run workflow) للتأكد.

## 7. حل المشاكل

### إحدى المنصات مش بتنشر

1. افتحي **تاب Actions** على GitHub.
2. اضغطي على التشغيل الفاشل (اللي عليه X أحمر).
3. افتحي الخطوة الفاشلة → اقري رسالة الخطأ في الآخر.
4. الأسباب الشائعة:
   - **"session expired" أو التحويل لصفحة دخول** ← الكوكيز انتهت ← شوفي [القسم 6](#6-الصيانة-تحديث-كوكيز-تسجيل-الدخول).
   - **"Queue is empty"** ← مهمة السحب اليومية ما شغّلت ← شغّليها يدوياً: Actions → Scrape → Run workflow.
   - **"chat not found" (تيليجرام)** ← البوت اتشال من قناتك كأدمن ← أعيدي إضافته.

### رابط الأفلييت ما بيشتغل (خطأ 404)

البوت المفروض دايماً يعمل روابط نظيفة `amazon.com/dp/ASIN?tag=electron039ae-20`. لو شفتي شيء تاني (زي `/sspa/click`)، حصل خطأ ما — تواصلي مع المطوّر.

### عدّلت ملف إعدادات والبوت وقف

روحي لتاب Actions → دوّري على الكوميت بتاعك في الـ history → لو ظهر باللون الأخضر يعني اتبنى صح. لو فشل، اقري الخطأ، وارجعي للملف، اضغطي ✏️، وارجعي التعديل أو صلّحي الصياغة.

### Pinterest بيحفظ المنشورات كمسودات بدل ما ينشرها

عادةً بسبب تغييرات في واجهة Pinterest أو مشاكل حجم الصورة. تواصلي مع المطوّر.

## 8. فهم بنية الملفات

مش لازم تلمسي معظمهم — لكن هنا خريطة عشان ما يكونش أي ملف غامض:

| الملف / الفولدر | الوظيفة |
|---|---|
| `main.py` | المدير الرئيسي — يقرّر يعمل scrape ولا post |
| `config.example.json` | **ملف الإعدادات الرئيسي بتاعك** — عدّلي فيه عشان تخصّصي البوت |
| `scraper/amazon_scraper.py` | يقرأ amazon.com ويسحب المنتجات |
| `scraper/categories.json` | قائمة التصنيفات اللي البوت يدور بينها |
| `content/caption.py` | يبني الكابشن التسويقي لكل منشور |
| `content/screenshot_builder.py` | ياخد سكرين شوت لصفحة المنتج على أمازون |
| `content/video_builder.py` | يبني الفيديو المناسب لـ TikTok |
| `posters/telegram_poster.py` | ينشر على تيليجرام |
| `posters/x_poster.py` | ينشر على X (تويتر) |
| `posters/pinterest_poster.py` | ينشر على Pinterest |
| `core/config.py` | يقرأ الإعدادات والأسرار |
| `state/queue.json` | قائمة اليوم من المنتجات (تدار تلقائياً) |
| `state/posted.json` | سجل المنتجات اللي اتنشرت (منع التكرار) |
| `.github/workflows/post.yml` | جدول النشر |
| `.github/workflows/scrape.yml` | جدول السحب اليومي |
| `assets/fonts/` | خط عربي مستخدم في الصور والفيديوهات |
| `requirements.txt` | حزم Python اللي البوت يحتاجها |
