# بوت النشر التلقائي لعروض أمازون

> 🇬🇧 **In English:** [README.md](README.md)

بوت يعمل آلياً، يجلب المنتجات من **أمازون السعودية**، يبني صورة مميزة + فيديو قصير، وينشرها على **تيليجرام** و **X (تويتر)** و **بينترست** في 10 أوقات ثابتة كل يوم — بدون أي تدخل يدومي، مستضاف مجاناً على GitHub Actions.

## 1. وظيفة البوت

في كل وقت من أوقات النشر (10 مرات يومياً)، البوت بـ:

1. يختار المنتج التالي من قائمة 10 منتجات يومية من أمازون.سعودية.
2. يبني **صورة 1080×1080** عليها صورة المنتج + الاسم + السعر + زر اطلب الآن.
3. يبني **فيديو عمودي 1080×1920** مناسب لـ TikTok.
4. يكتب **كابشن تسويقي بالعربية** بقوالب متنوعة عشان البوستات ما تكون متشابهة.
5. يضيف **رابط الأفلييت السعودي** (`tikshoping01-21`) لتيليجرام و X، و **رابط الأفلييت الأمريكي** (`electron039ae-20`) لبينترست.
6. ينشر:
   - **تيليجرام** → صورة + فيديو + كابشن (القناة هي الأرشيف المركزي)
   - **X (تويتر)** → صورة + كابشن مختصر
   - **بينترست** → صورة + كابشن + رابط الوجهة
7. يسجل المنتج كمنشور عشان ما يتكررش.

مرة واحدة يومياً في **5 صباحاً بتوقيت الرياض**، يشتغل ورك فلو منفصل يجيب 10 منتجات جديدة للقائمة.

## 2. جدول النشر اليومي

النشر بيتم في الأوقات دي (**بتوقيت الرياض UTC+3**):

```
09:00 · 10:00 · 12:00 · 14:00 · 16:00 · 17:00 · 18:00 · 20:00 · 21:00 · 22:00
```

(الجدول محدد في ملف `.github/workflows/post.yml` لو حبيت تعدل عليه لاحقاً — شوف [الإعدادات](#8-إعدادات-قابلة-للتعديل).)

## 3. الحسابات المطلوبة

قبل ما تبدأ، تأكد إن عندك:

- [ ] حساب **GitHub** — مجاني. (الخطوة 4.1 تحت.)
- [ ] **قناة تيليجرام** + **بوت تيليجرام** مرتبط بيها. (الخطوة 4.6.)
- [ ] حساب **X (تويتر)**.
- [ ] حساب **بينترست** فيه بورد جاهز (الاسم الافتراضي: "for amazon").
- [ ] حساب **Amazon Associates** فيه تاجين:
   - تاج سعودي (بينتهي بـ `-21`)
   - تاج أمريكي (بينتهي بـ `-20`)
- [ ] **كمبيوتر** (ويندوز / ماك / لينكس) — هتستخدمه **مرة واحدة بس** أثناء الإعداد لحفظ بيانات الدخول. بعد كده البوت بيشتغل على سيرفرات GitHub لوحده.

## 4. الإعداد لمرة واحدة

الوقت المتوقع: **30 لـ 45 دقيقة** لو مشيت بالترتيب.

### 4.1 إنشاء حساب GitHub

1. روح على https://github.com/signup
2. استخدم أي إيميل. اختار اسم مستخدم وباسورد.
3. فعل الإيميل.
4. **ابعت اسم المستخدم بتاعك** للمطور اللي سلمك المشروع — هو هينقل لك المشروع على حسابك.

> 💡 الخطة المجانية في GitHub كافية. البوت بيستهلك تقريباً 50 دقيقة شهرياً، والحد المجاني 2,000 دقيقة شهرياً.

### 4.2 قبول نقل المشروع

بعد ما المطور ينقل المشروع:

1. هيوصلك إيميل من GitHub: *"You have been added as the owner of …"*
2. اضغط الرابط → اضغط **Accept** → خلاص. المشروع دلوقتي عندك على `https://github.com/USERNAME/Affilate_bot`.

### 4.3 تثبيت Python على جهازك

هتحتاج Python أثناء **الإعداد بس** عشان تحفظ الكوكيز — بعد كده تقدر تحذفه لو حبيت.

**ويندوز:**
1. روح على https://www.python.org/downloads/
2. نزل أحدث نسخة Python 3.x.
3. شغل الإنستولر. **مهم جداً:** علم على المربع "**Add Python to PATH**" في أول شاشة.
4. اضغط "Install Now".
5. افتح PowerShell واكتب `python --version`. لازم تشوف `Python 3.x.x`.

**ماك:**
- افتح Terminal → اكتب `brew install python3` (أو نزله من python.org).

### 4.4 تنزيل المشروع على جهازك

طريقتين — اختار واحدة:

**الطريقة A (الأسهل، بدون Git):**
1. افتح المشروع على GitHub.
2. اضغط زر **Code** الأخضر → **Download ZIP**.
3. فك ضغط الملف في مكان سهل (مثلاً `Desktop\Affilate_bot`).

**الطريقة B (باستخدام Git، أحسن):**
1. ثبت Git: https://git-scm.com/downloads
2. افتح PowerShell → روح للمكان اللي عايز المشروع فيه (مثلاً `cd Desktop`).
3. اكتب: `git clone https://github.com/USERNAME/Affilate_bot.git`

### 4.5 تثبيت مكتبات المشروع

في PowerShell، ادخل **جوه** فولدر المشروع وثبت المكتبات:

```powershell
cd path\to\Affilate_bot
pip install -r requirements.txt
python -m playwright install chromium
```

الأمر الأول بيثبت مكتبات Python. الثاني بيثبت المتصفح اللي البوت بيستخدمه لـ X و Pinterest. الاتنين ممكن ياخدوا شوية دقايق.

### 4.6 إنشاء بوت تيليجرام

1. افتح تيليجرام → دور على **@BotFather** → ابدأ محادثة.
2. ابعت `/newbot` → اتبع التعليمات:
   - اسم البوت اللي بيظهر (مثلاً "Smart Deals Bot").
   - يوزرنيم البوت (لازم ينتهي بـ `bot`، مثلاً `smart_deals_bot`).
3. BotFather هيرد عليك بـ **توكن** شكله `1234567890:AAH...`. **احفظه — هتحتاجه بعدين.**
4. افتح القناة بتاعتك → اضغط اسم القناة فوق → **Administrators** → **Add Admin** → دور على يوزرنيم البوت → ضيفه → فعل صلاحية "**Post Messages**" → احفظ.

### 4.7 حفظ بيانات تسجيل الدخول لـ X (تويتر)

البوت محتاج يكون مسجل دخول في X عشان ينشر. بتسجل دخول مرة واحدة على جهازك، تحفظ الجلسة، وترفعها كسر (Secret) على GitHub.

1. **اعمل ملف config محلي.** جوه فولدر المشروع، انسخ ملف `config.example.json`، وغير اسمه لـ `config.json`. الملف ده يفضل على جهازك — مش بيترفع.

2. في PowerShell، من جوه فولدر المشروع، اكتب:
   ```powershell
   python -m posters.x_poster --login
   ```

3. هيفتح متصفح عليه صفحة تسجيل دخول X.

4. **سجل دخول بحساب X بتاعك.** كمل أي تأكيد ثنائي (2FA) أو تأكيد رقم تيليفون.

5. لما تشوف الصفحة الرئيسية لـ X (يعني عملت دخول بنجاح)، ارجع لـ PowerShell و**اضغط Enter** زي التعليمات.

6. هتشوف `Cookies saved to ...x_cookies.json` و `Saved N cookies.` خلاص — ملف `x_cookies.json` فيه جلستك دلوقتي.

### 4.8 حفظ بيانات تسجيل الدخول لـ Pinterest

1. افتح `config.json` (اللي عملته في خطوة 4.7) في Notepad أو أي محرر نصوص.

2. في قسم `pinterest`، استبدل البيانات الموجودة بإيميل وباسورد Pinterest بتاعك:
   ```json
   "pinterest": {
     "email": "your_email@example.com",
     "password": "your_password",
     "default_board": "for amazon"
   },
   ```
   احفظ الملف.

3. احذف ملف الكوكيز القديم لو موجود:
   ```powershell
   Remove-Item pinterest_cookies.json -ErrorAction SilentlyContinue
   ```

4. شغل بوست Pinterest في وضع المتصفح المرئي:
   ```powershell
   python -m posters.pinterest_poster --headed
   ```

5. هيفتح متصفح، البوت هيسجل دخول تلقائياً، وبعدين هينشر **بن تجريبي صغير** على حسابك. (تقدر تمسحه من Pinterest بعد كده — هو بس صورة placeholder.)

6. بعد ما الكود يخلص، ملف `pinterest_cookies.json` فيه جلستك دلوقتي.

> ℹ️ لو Pinterest طلب كود تأكيد أو CAPTCHA، هتشوف المتصفح متوقف — كمل التأكيد يدوياً والكود هيكمل لوحده.

### 4.9 إضافة الأسرار على GitHub

دي أهم خطوة — الأسرار دي هي اللي البوت بيستخدمها على السحابة.

1. على GitHub، روح للمشروع → **Settings** (فوق على اليمين) → **Secrets and variables** → **Actions**.

2. لكل صف في الجدول، اضغط **New repository secret**، اكتب الاسم **بالظبط** زي ما هو، والصق القيمة:

   | اسم السر | القيمة |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | التوكن من BotFather (خطوة 4.6) |
   | `TELEGRAM_CHANNEL_ID` | يوزرنيم القناة بتاعتك مع @، مثلاً `@LunaDealsAd` |
   | `PINTEREST_EMAIL` | إيميل Pinterest بتاعك |
   | `PINTEREST_PASSWORD` | باسورد Pinterest بتاعك |
   | `X_COOKIES_JSON` | **محتوى ملف** `x_cookies.json` كله (افتحه في Notepad → Ctrl+A → Ctrl+C → الصق) |
   | `PINTEREST_COOKIES_JSON` | **محتوى ملف** `pinterest_cookies.json` كله |

3. بعد ما تحفظ الـ6 أسرار، المفروض تشوف 6 صفوف في الصفحة.

> ⚠️ ما تحطش علامات تنصيص حوالين القيم. الصق النص خام بس.

### 4.10 أول تشغيل تجريبي

1. على GitHub، اضغط تاب **Actions**.
2. في القائمة على الشمال، اضغط **"Post — publish next product to all 3 platforms"**.
3. على اليمين، اضغط **Run workflow** → سيب الفرع `main` → اضغط زر **Run workflow** الأخضر.
4. استنى 5 ثواني → اعمل refresh. هتلاقي run جديد ظهر. اضغط عليه عشان تتفرج لايف.
5. بعد 3 لـ 5 دقايق، كل الخطوات لازم تكون خضرا ✅.
6. افتح تيليجرام و X و Pinterest — لازم تلاقي بوست جديد على التلاتة.

لو حصلت مشكلة، شوف [حل المشاكل](#7-حل-المشاكل).

## 5. التشغيل اليومي

بعد ما تخلص الإعداد، البوت بيشتغل لوحده:

- **5 صباحاً بتوقيت الرياض يومياً** — بيجيب 10 منتجات جديدة.
- **10 مرات يومياً** (شوف [الجدول](#2-جدول-النشر-اليومي)) — بينشر منتج على التلات منصات.

مش محتاج تعمل أي حاجة. بس راجع البوستات إنها بتنزل (تيليجرام أسهل مكان للتأكد).

**GitHub هيبعتلك إيميل** تلقائياً لو في تشغيل فشل.

## 6. الصيانة (تحديث الكوكيز)

كوكيز الدخول لـ X و Pinterest **بتنتهي صلاحيتها كل شهر لـ 3 شهور**. لما ده يحصل، البوت هيبدأ يفشل في المنصات دي (تيليجرام هيفضل شغال).

**عشان تحدثها:**

1. على جهازك، اعمل **خطوة 4.7** تاني لـ X و **خطوة 4.8** لـ Pinterest. كوكيز جديدة هتتحفظ.
2. روح GitHub → Settings → Secrets → Actions → اضغط القلم ✏️ جنب `X_COOKIES_JSON` (أو `PINTEREST_COOKIES_JSON`) → الصق المحتوى الجديد → Update.
3. شغل ورك فلو Post يدوياً (خطوة 4.10) عشان تتأكد.

العملية ديا بتاخد 5 دقايق.

## 7. حل المشاكل

### في تشغيل فشل — أعرف منين السبب؟

1. على GitHub → تاب **Actions** → اضغط على التشغيل الفاشل.
2. اضغط على الـ job اللي فشل → افتح الخطوة اللي عليها ❌.
3. اقرا رسالة الخطأ في الآخر.
4. انزل آخر الصفحة عشان تلاقي **"Artifacts"** — البوسترز الفاشلة بترفع debug screenshots هناك.

### تيليجرام بيقول "chat not found" أو "not enough rights"

البوت مش admin في القناة. اعمل خطوة 4.6 الجزء الثاني تاني: افتح القناة → Administrators → Add Admin → دور على البوت → فعل "Post Messages".

### X / Pinterest بيقول "session expired" أو بيحول للوجن

الكوكيز انتهت. حدثها — شوف [الصيانة](#6-الصيانة-تحديث-الكوكيز).

### أمازون رجع CAPTCHA / robot check

نادر بس بيحصل. شغل الورك فلو تاني — أمازون عادة بيرجع. لو فضل المشكلة، استنى ساعة.

### القائمة فاضية

ورك فلو الـ scrape ما اشتغلش. شغله يدوياً: **Actions** → "Scrape — refill product queue" → **Run workflow**.

## 8. إعدادات قابلة للتعديل

أغلب الحاجات اللي ممكن تعدلها موجودة في **`config.example.json`** (اللي بيتحول لـ `config.json` لما البوت يشتغل على السيرفر). عدل الملف ده في المشروع، اعمل commit + push، والتشغيل اللي بعده هياخد التعديلات.

| الإعداد | شرحه |
|---|---|
| `schedule_times` | للعرض بس؛ الجدول الفعلي في `.github/workflows/post.yml` |
| `products_per_day` | كام منتج بيتم جلبهم يومياً (افتراضي 10) |
| `prioritize_discounts` | لو `true`، المنتجات اللي عليها خصم بتتنشر الأول |
| `amazon.source_url` | رابط بحث احتياطي لو ما فيش categories |
| `amazon.tag_us` | تاج الأفلييت الأمريكي المطبق على كل الروابط في كل المنصات |
| `pinterest.default_board` | اسم البورد اللي البوت بينشر فيه على Pinterest |
| `captions.hashtags` | الهاشتاجات اللي بتتضاف لكل كابشن |

عشان تغير **أوقات النشر**: عدل سطور الـ `cron:` في `.github/workflows/post.yml`. الأوقات بتوقيت UTC — اطرح 3 ساعات من توقيت الرياض.

عشان تغير **التصنيفات**: عدل ملف `scraper/categories.json`.
